## 范围与基线

本说明书在本轮第二版改动开始前登记，约定保留的核心业务、新增改进、模块合同与验收方式。第一版已有实现和验证记录，来源为https://github.com/Alice1332/-111，源码集成提交3645567；不把第一版开发历史重新表述为第二版从零开发。当前第二版实现尚未开始，以下内容为需求和计划，不是完成声明。

应用沿用虚构的旧图书馆A-017失踪档案调查，保留校园门卫室、旧图书馆、器材储藏室三个场景，至少12个业务事件、6条线索和两个条件结局。使用ArkTS、ArkUI与Stage模型，离线运行，Preferences持久化。拟用本机DevEco Studio 26.0.1.290及配套SDK构建，最低兼容配置沿用API12；实际版本和兼容结果在本轮验证后记录。

## 模块与数据模型

拟沿用页面Index、GameEngine、SaveCodec、SaveRepository、TextStore与PreferencesStore分层。页面向引擎提交操作，经仓库保存成功后再发布状态；仓库调用编解码和存储接口，解码通过引擎重放历史。故障注入放在测试适配层，不在正式用户界面暴露修改存档的入口。

表4.1 数据约束

| 字段或实体 | 约束 | 保存与恢复 |
| --- | --- | --- |
| sceneId | gate、library、storage之一且当前可进入 | 每次移动保存 |
| events与clues | 仅目录ID、不重复，顺序与历史一致 | 快照并重放核对 |
| history | 0至12条，eventId与choice成对记录 | 按真实条件逐步重放 |
| cooperation | 空、cooperate、accuse | 由E06派生 |
| suspect | 空、transfer、theft | 由E11派生 |
| ending | 空、truth、rush | 只由E12派生 |
| SaveEnvelope | version=1；payload字符串；checksum一致 | 每次读取先校验再重放 |
| current与backup | 一个主档，一个滚动有效备份 | 主档失败尝试备份；两档坏不自动覆盖 |

保存流程为验证状态、编码、读取旧主档、必要时备份、写新档、等待flush、发布状态。校验值不是安全签名，不用于抵抗恶意攻击；应用不存储真实身份、聊天或敏感信息。


## 接口合同与本人责任

表5.1 接口合同

| 接口 | 参数和返回 | 合同 |
| --- | --- | --- |
| GameEngine<br>move | state、scene → Transition | 仅允许已解锁场景，失败不改旧状态 |
| GameEngine<br>investigate | state、eventId、choice → Transition | 所有规则校验集中执行 |
| SaveCodec<br>encode / decode | state↔raw | decode失败抛错，不返回半有效状态 |
| TextStore | read、write、flush均返回Promise | 隔离平台能力与Mock |
| SaveRepository<br>load / save | LoadResult / Promise<void> | 错误向页面传递，禁止静默丢进度 |
| Index.commit | Transition → Promise<void> | busy期间不并发，保存成功后赋新状态 |
